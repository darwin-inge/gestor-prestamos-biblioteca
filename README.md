# Gestor de Préstamos - Biblioteca

Programa en Python, de consola, para llevar el control de los libros
prestados en una biblioteca.

## Funciones
- Registrar un nuevo préstamo (título del libro y nombre de la persona)
- Ver los libros prestados actualmente
- Devolver un libro (búsqueda por título, sin distinguir mayúsculas)
- Validación de entradas vacías y de opciones del menú

## Requisitos
- Python 3.8 o superior (no necesita librerías externas)

## Cómo ejecutarlo
```
python gestor_prestamos.py
```
